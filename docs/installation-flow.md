# 单命令安装流程

用户入口保持 `curl -fsSL https://install.thingspanel.io/install.sh | sh`。

已实现：Owner 共享网络内只监听 127.0.0.1，使用已有安全规则；脚本在拉取镜像后自动准备资源库与尚未执行的 SQL，再启动应用，不让用户手工拆步骤。迁移读取本次后端镜像携带的固定源码，社区库沿 sys_version 升级，Broker/Encore 沿校验台账执行，成功才记账；不清库、不覆盖已有身份或数据库数据。

通知会话校验使用安装时生成的私有 TLS 证书，经现有前端 Nginx 内部 8443 入口连接社区 API；该端口不发布到宿主机，保留生产 HTTPS 要求。新安装使用同一组持久凭据，重复安装保留它们。

先启动 PostgreSQL/Redis，再准备迁移、Owner/原生模块，最后启动后端/前端；根据实际依赖设置健康检查。只有前端 API、原生 API、通知认证入口、定时唤醒与必需容器状态通过才打印安装成功。失败明确退出，不把 SPA 的 200 页面当成后端健康。
